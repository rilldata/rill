# Cube Competitive Analysis (Aug 2026)

Research basis: cube.dev blog (full dated post index), docs.cube.dev (llms.txt + pages), cube.dev/pricing, github.com/cube-js/cube, press/analyst coverage, HN/G2/third-party comparisons, and the Rill codebase + docs.rilldata.com. Structure mirrors [`../omni/`](../omni/).

**TL;DR:** Cube pivoted from headless semantic layer to "agentic analytics platform" (D3 launch Jun 2025 → GA + rebrand Oct 2025) and has shipped an AI/agent feature roughly every two weeks since — skills, rules, certified queries, evals-in-CI, AI Studio, Slack agent, outbound MCP connectors, scheduled tasks, Python analysis, embedded agentic analytics. Its cracks: no data plane (pre-aggregation engineering is its performance tax and top user complaint), a 100% Cloud-gated AI platform (MCP at $80/dev/mo Premium; OSS "falling behind"), and a middleware position being commoditized by Snowflake/Databricks/dbt. Rill's counter: agents that are fast by default (managed OLAP), open all the way down (whole product OSS incl. local write-capable MCP), and able to *build* projects, not just query them. Biggest Rill gaps to close: AI operationalization packaging (skills/rules/evals/Slack/admin), Postgres-wire SQL API, semantic joins, SCIM/audit.
